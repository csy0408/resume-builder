# 需求文档

> 版本: v1.0 | 最后更新: 2026-06-02

---

## 项目目标

面向开发者的智能简历制作平台。核心价值：同一个经历根据不同岗位 JD 自动切换描述侧重点，生成高度匹配的定制简历。

---

## 用户故事

### US-1: 经历录入
- **US-1.1** 作为开发者，我可以通过 AI 自动扫描项目目录，自动提取开发经历
- **US-1.2** 作为用户，我可以上传已有简历（PDF/Word），AI 自动解析并填充信息
- **US-1.3** 作为用户，我可以手动填写所有个人信息和经历
- **US-1.4** 所有 AI 提取的内容，我都可以手动修改和确认

### US-2: JD 匹配
- **US-2.1** 作为求职者，我可以粘贴岗位 JD 或 URL，AI 自动解析岗位要求
- **US-2.2** 作为求职者，AI 会根据 JD 自动匹配我最相关的经历
- **US-2.3** 作为求职者，同一经历可以针对不同岗位有不同的描述版本（变体）
- **US-2.4** 我可以看到简历与 JD 的匹配度评分及差距分析

### US-3: 简历生成
- **US-3.1** 作为用户，我可以从 3 套模板中选择喜欢的样式
- **US-3.2** 作为用户，我可以在线编辑简历内容
- **US-3.3** 作为用户，我可以使用 AI 润色/STAR 扩写/调整语气
- **US-3.4** 作为用户，我可以导出 PDF 和 Word 格式
- **US-3.5** 作为用户，同一 JD 可以生成 A/B 两个版本对比选择

### US-4: 管理与同步
- **US-4.1** 作为用户，数据默认保存在浏览器本地
- **US-4.2** 作为用户，我可以导出 JSON 文件备份和导入恢复
- **US-4.3** 作为用户，简历历史版本自动保存，支持版本对比
- **US-4.4** 作为用户，经历可维护中英文双版本

### US-5: 通用
- **US-5.1** 作为用户，界面简洁直观、淡蓝色主题、颜色可切换
- **US-5.2** 作为用户，我可以填入自己的 Claude API Key

## 非功能需求

- **性能**：首次加载 < 3s，AI 操作有 loading 状态
- **安全**：API Key 仅存 localStorage，不上传服务器
- **兼容**：Chrome/Firefox/Edge 最新版
- **响应式**：桌面端为主，移动端可查看
