简历制作平台 — 技术架构方案

公开部署 + 开源 + AI 驱动 + 纯前端（无需后端）

架构概览

纯前端 SPA → GitHub Pages 部署，用户自带 API Key
📥 经历输入
▪ AI 自动扫描项目
▪ 手动填写表单
▪ JSON 导入
🧠 JD 匹配引擎
▪ Claude API
▪ 语义匹配
▪ 生成定制简历
📄 简历输出
▪ 模板选择 & 编辑
▪ 导出 PDF / Word
▪ JSON 备份
localStorage（默认）⇄ JSON 文件（导出备份 / 跨设备同步）

两种实现路径

A

React + Vite 全栈前端

组件化开发，生态丰富。简历编辑器用富文本库（如 TipTap），PDF 用 jsPDF，Word 用 docx.js。开发效率高，适合复杂交互。

B

纯 HTML/CSS/JS（零依赖）

不依赖框架，体积小加载快。所有功能从零手写，部署简单。但复杂 UI（编辑器、拖拽）开发工作量大。

我的推荐

推荐 A — React + Vite，理由：

  • 开源社区最活跃，方便其他人参与贡献
  • GitHub Pages 部署只需 npm run build + GitHub Actions
  • 简历编辑器、模板切换等交互复杂，React 组件化天然适合
  • Tiptap、jsPDF、docx.js 等库成熟稳定
  • Claude API 调用在前端直接用 Anthropic SDK

用户需要提供自己的 Claude API Key（或平台提供默认 Key + 用量限制）
